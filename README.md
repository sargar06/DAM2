# 📚 DAM2 — Desarrollo de Aplicaciones Multiplataforma (2º curso)

Repositorio con los apuntes, ejercicios y proyectos desarrollados durante el **segundo curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Este espacio recoge el material de cada módulo profesional trabajado a lo largo del curso, organizado en carpetas independientes para facilitar la consulta y el seguimiento del contenido.

---

## 🗂️ Estructura del repositorio

```
📦 DAM2
├── 📁 ACCESO-DATOS
├── 📁 FRAMEWORKS
├── 📁 INTERFACES
├── 📁 MULTIMEDIA-MOVILES
├── 📁 PROYECTO
├── 📁 SERVICIOS-PROCESOS
└── 📁 SISTEMAS-GESTION-EMPRESARIAL
```

---

## 📖 Módulos profesionales

| Carpeta | Módulo | Descripción |
|---|---|---|
| 🗃️ [`ACCESO-DATOS`](./ACCESO-DATOS) | **Acceso a Datos** | Persistencia de información: ficheros, JDBC, JPA/Hibernate, bases de datos relacionales y NoSQL. |
| 🧩 [`FRAMEWORKS`](./FRAMEWORKS) | **Programación de Servicios y Procesos / Frameworks** | Uso de frameworks de desarrollo (Spring, entre otros) para la creación de aplicaciones robustas. |
| 🎨 [`INTERFACES`](./INTERFACES) | **Desarrollo de Interfaces** | Diseño e implementación de interfaces gráficas de usuario (GUI) multiplataforma. |
| 📱 [`MULTIMEDIA-MOVILES`](./MULTIMEDIA-MOVILES) | **Programación Multimedia y Dispositivos Móviles** | Desarrollo de aplicaciones para dispositivos móviles y tratamiento de contenido multimedia. |
| 🚀 [`PROYECTO`](./PROYECTO) | **Proyecto de Desarrollo de Aplicaciones Multiplataforma** | Proyecto final integrador que aplica los conocimientos adquiridos en el ciclo. |
| 🔗 [`SERVICIOS-PROCESOS`](./SERVICIOS-PROCESOS) | **Programación de Servicios y Procesos** | Concurrencia, procesos, hilos y desarrollo de servicios en red. |
| 🏢 [`SISTEMAS-GESTION-EMPRESARIAL`](./SISTEMAS-GESTION-EMPRESARIAL) | **Sistemas de Gestión Empresarial** | ERP, CRM y sistemas de información orientados a la gestión de empresas. |

---

## 🎯 Objetivo del repositorio

- Centralizar el material de estudio de cada módulo.
- Servir como referencia y repaso para prácticas y proyectos.
- Documentar el progreso a lo largo del curso.
